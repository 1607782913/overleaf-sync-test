TDSC LaTeX starter bundle

文件说明：
- main.tex：视觉上更接近你给出的 IEEE Xplore 已发表 TDSC 论文截图（衬线标题、两栏正文、Abstract—样式）。
- main_official_compsoc.tex：IEEE Computer Society 官方 journal 模板结构（compsoc 模式），用于与当前官方投稿模板核对。
- IEEEtran.cls：IEEEtran 类文件，上传到 Overleaf 后可直接编译。
- references.bib：参考文献数据库。

Overleaf 使用：
1. Overleaf -> New Project -> Upload Project。
2. 直接上传整个 ZIP。
3. 默认使用 main.tex 编译即可。
4. Compiler 选择 pdfLaTeX。
5. 把 title / author / abstract / section 内容替换成你的论文内容。
6. 参考文献放到 references.bib。

注意：
你截图展示的是 IEEE 已发表论文（Version of Record）的生产排版效果。IEEE 接收后可能再次做出版级排版，
因此作者可获得的投稿模板与 Xplore 最终 PDF 不一定像素级一致。正式投稿前请使用 IEEE Template Selector 对照当期要求。
